# presentation

Open `index.html` directly in a browser. Three.js is bundled locally at
`vendor/three/three.min.js`, so the 3D scene does not require a CDN connection.
See `vendor/three/LICENSE` for its license.

All page images, including the chapter photography and architecture diagram, are
stored locally so the presentation can display them without a CDN connection.

The site includes a canonical URL, social-sharing metadata, Person structured
data, `robots.txt`, and `sitemap.xml` for search crawlers. After publishing,
verify the site in Google Search Console and submit
`https://alexove95.github.io/presentation/sitemap.xml`. Search indexing and
ranking are controlled by search engines and are not immediate or guaranteed.
